# 现实炒股 ep01 · Seedance / 即梦 生产包

> **片名：** 一买就跌，一卖就涨  
> **时长：** 18s（4 镜裁剪拼）｜**比例：** 9:16｜**系列 A 试播**  
> **路线：** 即梦里用 **Seedance** 逐镜图生视频 → 剪映拼片配音  
> **不要用** Coze 一键包做本集试播（见文末说明）

---

## 〇、操作总览（照着做）

```
1. 上传角色垫图（三张）
2. 每镜：先出「首帧图」→ 再 Seedance 图生视频（建议 5s）
3. 四段视频进剪映：裁成 3+4+5+6s → 配音 → 叠字幕
4. 对照质检清单过片
```

| 镜 | 剧情 | 生成时长 | 剪映裁切 | 主垫图 | 情绪参考 |
|----|------|----------|----------|--------|----------|
| 01 | 追涨买入 | 5s | 取前 **3s** | `ref_01` | `lulu_03_小得意` |
| 02 | 买就跌 | 5s | 取前 **4s** | `ref_01` | `lulu_01_心虚` |
| 03 | 卖就涨 | 5s | 取满 **5s** | `ref_01` | `lulu_01_心虚` |
| 04 | 躺平按 F5 | 5s 或 10s | 裁 **6s**（10s 取中间 6s） | `ref_01` | — |

**预算建议：** 先用每日免费积分只跑 **镜01 + 镜02**，角色像了再开会员跑 03/04。每镜允许重抽 2～3 次。

## 二、Seedance 全局参数（每镜相同，除非注明）

在即梦选 **图生视频 / Seedance**（有 2.0 优先 2.0；没有则用当前默认 Seedance）：

| 项 | 值 |
|----|-----|
| 比例 | **9:16** 竖屏 |
| 分辨率 | 试播用 **720p**；定稿再 1080p（省积分） |
| 时长 | 默认 **5s**（镜04 可选 10s） |
| 运动 / 动态幅度 | **中偏低**（约 40%～55%） |
| 创意发散 / 想象力 | **偏低**（约 35%～45%），防角色跑偏 |
| 有声 / 无声 | **无声**（台词剪映配，省钱且可控） |
| 水印 | 会员去水印后再导出发布 |

**造型锁定句（每镜 prompt 末尾必须粘贴）：**
```
Q版3D明黄水豚男孩，橘色短裤，头顶小橘子和绿叶，蓝色大眼，大门牙，橘色圆鼻头，水豚噜噜风格，与参考图一致，角色稳定不变形
```

**负向提示（有负向框就填；没有则把关键词写进正向末尾「避免：…」）：**
```
棕色水豚，写实水豚，河马，2D平面，扁平插画，多手多脚，面部崩坏，真实股票代码，荐股文字，涨跌百分比小字，血腥，治愈升华，情侣第二角色，女水豚
```

## 三、逐镜生产（首帧 → 视频）

> **推荐两步：**  
> A. **参考生图 / 图生图** 出首帧（垫 `ref_01` + 情绪图）  
> B. **Seedance 图生视频**：首帧作输入图，再贴「动作 prompt」  
>  
> 若界面支持「参考图 + 文本直接出视频」，可跳过 A，但角色一致性通常不如先锁首帧。

### 镜01｜追涨买入｜裁 3s

**目标：** 兴奋盯手机 → 猛点买入；暖色沙发近景。

#### A. 首帧生图 prompt
```
近景，9:16竖屏，暖色客厅沙发。
一只明黄Q版3D水豚男孩坐在沙发上，橘色短裤，头顶小橘子绿叶，蓝色大眼放光，张嘴傻笑，小得意表情。
双手捧着手机，屏幕朝向镜头，屏幕上是模糊的红色上涨K线示意图，没有可读文字和股票代码。
手指悬在买入按钮附近，准备点击。
Q版3D渲染，柔和暖光，搞笑不煽情。
Q版3D明黄水豚男孩，橘色短裤，头顶小橘子和绿叶，蓝色大眼，大门牙，橘色圆鼻头，水豚噜噜风格，与参考图一致，角色稳定不变形
```
- 垫图：`ref_01`（必须）+ `lulu_03_小得意`（若可垫多张）
- 出 2～4 张，选 **脸最像 + 手机最大** 的一张作首帧

#### B. Seedance 图生视频 prompt
```
近景，9:16竖屏。
水豚男孩兴奋盯着手机，眼睛放光，手指猛点屏幕买入按钮，身体微微前倾，嘴角上扬傻笑。
手机屏幕红色K线轻微上扬闪动，无清晰文字。
轻微镜头推进，动作轻快搞笑，不煽情。
角色外形与首帧完全一致，Q版3D明黄水豚，橘色短裤，头顶小橘子。
```
- 输入图：镜01 首帧  
- 时长 5s｜运动中偏低｜创意偏低  
- 剪映：取 **0:00–0:03**

**配音：** 「突破了！冲！」  
**字幕：** 突破！冲！

```

手机屏幕朝向镜头，屏幕上是模糊的绿色下跌K线示意图，账户数字发绿，没有可读股票代码。
Q版3D渲染，搞笑尴尬气氛。
Q版3D明黄水豚男孩，橘色短裤，头顶小橘子和绿叶，蓝色大眼，大门牙，橘色圆鼻头，水豚噜噜风格，与参考图一致，角色稳定不变形
```
- 垫图：`ref_01` + `lulu_01_心虚`

#### B. Seedance 图生视频 prompt
```
近景，9:16竖屏。
水豚男孩看着手机，屏幕K线瞬间跳水变绿，他从勉强镇定变成心虚尴尬，额头冒汗，嘴角抽搐，身体微微后缩。
无清晰文字和股票代码。
动作幅度小，表情变化为主，搞笑。
角色外形与首帧完全一致，Q版3D明黄水豚，橘色短裤，头顶小橘子。
```
- 时长 5s｜运动 **偏低**（约 35%～45%）  
- 剪映：取 **0:00–0:04**

**配音：** 「……没事，技术性调整。」（虚一点）  
**字幕：** `账户 -3.2%` ← **必须剪映后期叠字，不要让模型生成小字**

### 镜04｜躺平｜裁 6s

**目标：** 沙发躺平，生无可恋，举手机按刷新；冷收场。

#### A. 首帧生图 prompt
```
中景，9:16竖屏，暖色客厅沙发。
明黄Q版3D水豚男孩平躺在沙发上，生无可恋脸，单手举着手机，屏幕朝向自己，屏幕隐约发绿。
另一只手无力垂着，头顶小橘子还在，橘色短裤可见。
背景柔和虚化，慵懒滑稽，不煽情不治愈。
Q版3D明黄水豚男孩，橘色短裤，头顶小橘子和绿叶，蓝色大眼，大门牙，橘色圆鼻头，水豚噜噜风格，与参考图一致，角色稳定不变形
```
- 垫图：`ref_01`（表情偏丧，不要用小得意）

#### B. Seedance 图生视频 prompt
```
中景，9:16竖屏。
水豚男孩躺在沙发上生无可恋，拇指无力地反复点击手机刷新，屏幕轻微闪绿光。
镜头缓慢轻微拉远，冷收场，不安慰不升华。
动作很少，慵懒滑稽。
角色外形与首帧完全一致，Q版3D明黄水豚，橘色短裤，头顶小橘子。
```
- 时长：**5s** 若动作够用；不够则 **10s** 后取中间 6s  
- 运动 **低**（约 25%～35%）  
- 剪映：凑满 **6s**（可微减速，勿加治愈音乐）

**配音：** 无（或极轻「……」）  
**字幕：** 今天又白给了。

> 脚本里「快切重复一次买卖」**不要用 Seedance 再生成**——剪映里把镜01～03 各抽 0.3～0.5s 快闪拼在镜04 前即可（可选，没有也行）。

## 四、剪映组装单

### 时间轴

| 轨 | 0:00–0:03 | 0:03–0:07 | 0:07–0:12 | 0:12–0:18 |
|----|-----------|-----------|-----------|-----------|
| 视频 | 镜01 | 镜02 | 镜03 | 镜04 |
| 配音 | 突破了！冲！ | ……没事，技术性调整。 | 卖飞了？！ | （空） |
| 字幕 | 突破！冲！ | 账户 -3.2% | 卖飞 +10% | 今天又白给了。 |

### 配音

| 时间 | 台词 | 音色 | 语速 |
|------|------|------|------|
| ~0:01 | 突破了！冲！ | 阳光男孩 / 趣味男声 | 1.15 |
| ~0:04 | ……没事，技术性调整。 | 同上 | 1.0，略虚 |
| ~0:08 | 卖飞了？！ | 同上 | 1.2 |
| 结尾 | — | — | 仅字幕 |

### 音效（可选）

- 镜01：点击音  
- 镜02：跳水「嗖」  
- 镜03：拉升「叮」  
- 镜04：BGM 滑稽收尾 abrupt stop（**不要**暖心钢琴）

### 转场

硬切为主；镜03→04 可短黑场 2～4 帧。禁止闪白「重生」特效。

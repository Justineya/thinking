# 噜妹很坏 · Prompt 构造规则（必遵）

> 复盘沉淀：角色**穿着变化**和**背景连贯**不过关时，模型会「凭空出现」、场景跳切、细节丢失。  
> 再补：竞品噜噜**表情更跳、更夸张**——每句对白都要挂一个表情词，禁止全程一张脸。

## 0. 噜噜三套换装参考（你已备齐）

把素材按这个命名收进 `噜噜/角色资产/`（或即梦素材库同名）：

| 代号 | 穿着 | 用于哪些节拍 |
|------|------|----------------|
| **A · 短裤噜噜** | 只穿橘色短裤 | 日常卧室、被掀落地、开场（若未更衣） |
| **B · 穿衣服噜噜** | 有上衣/家居服 | 出门前、正式出门、非洗澡日常 |
| **C · 浴巾噜噜** | 白浴巾 | 进卫生间、冲澡、湿身过道、湿扑床 |

**用法铁律（Seedance）：**

1. **一段一个穿着参考**，不要一段里混垫 A+C 指望它自己换装。  
2. 换装发生在节拍交界：上一段片尾做「脱衣/围浴巾」动作 → 下一段改垫 **C** 开跑。  
3. 10 秒一条如果穿帮：拆成 **2～3 段图生视频**（卧室A/B → 卫生间C → 扑床掀飞C），再剪映接。  
4. 双人卧室可继续垫 `ref_04`，但**噜噜身体以当前穿着参考为准**写进 prompt。

```
开场穿衣服 B → 脱成浴巾 C → 湿奔湿扑 C → 落地仍是湿 C（橘子掉）
（若开场就要短裤版：开场改垫 A，再围浴巾切 C）
```

## 1. 穿着：分段写死，禁止只写结局装

每个场景节拍都要写清 **此刻穿什么** + **垫哪张参考**。

| 错误 | 正确 |
|------|------|
| 只写「去洗澡」 | 写：B衣服 → 可见围上浴巾 → 垫C冲澡 → 垫C湿奔 |
| 全程只垫一张 ref_01 | 按 A/B/C 换垫 |

**本线底线：** 不裸露。洗澡段落只允许 **C 浴巾**。

## 2. 背景：每段点名空间，写清怎么换场

公式：`空间A（穿着X）→ 可见移动 → 空间B（穿着Y）`

必须出现的连接词：推门、走廊、水渍脚印——禁止瞬移到床边。

## 3. 表情：一人一句，各挂一个表情（竞品差在这）

禁止「全程微笑/全程同一张霸道脸」。

**噜噜（表情要丰富、好欺负、夸张一点）：**

| 节拍 | 表情词（写进 prompt） |
|------|------------------------|
| 去洗澡 | 兴奋、眉开眼笑、挥手 |
| 冲澡 | 舒服闭眼或傻乐，水花里憨 |
| 湿奔扑床 | 得意忘形、嘴咧开 |
| 被骂/被掀 | 眼睛瞪圆、嘴巴大张 |
| 落地橘子掉 | 懵逼、眼泪打转或傻掉 |

**噜妹（霸道，但表情要有层次，不是死板凶）：**

| 节拍 | 表情词 |
|------|--------|
| 打发他去洗 | 不屑抱臂、下巴微抬 |
| 铺床 | 认真皱一点眉、专注 |
| 发现湿扑 | 震惊→怒意上涌（仍霸道，可凶萌） |
| 掀飞 | 咬牙发力、强势 |
| 下令收尾 | 俯视冷脸/傲，命令感 |

写法：**对白旁边紧跟表情**，例如：`噜噜眉开眼笑：「我要去洗澡啦！」`

## 4. 道具/身体细节：高潮可掉落

掀飞时：**头顶小橘子震掉滚落**——必须明写。

## 5. 时长

锚定 **10s**；少写秒表；细节保不住就拆段生成。

## 6. 垫图速查

| 场景 | 垫图 |
|------|------|
| 噜噜穿衣服 | **B** |
| 噜噜短裤 | **A** |
| 噜噜浴巾/湿身 | **C** |
| 双人比例 | `ref_04` |
| 噜妹霸道脸 | `ref_03` 或 `lumei_02_暴怒` |

## 7. 自检清单

- [ ] 本段穿着与垫图 A/B/C 一致  
- [ ] 有空间链条，无瞬移  
- [ ] 每句对白都有表情词  
- [ ] 高潮有橘子震掉  
- [ ] 无裸露、无第三人

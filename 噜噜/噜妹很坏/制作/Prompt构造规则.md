# 噜妹很坏 · Prompt 构造规则（必遵）

> 复盘沉淀：角色**穿着变化**和**背景连贯**不过关时，模型会「凭空出现」、场景跳切、细节丢失。

## 1. 穿着：分段写死，禁止只写结局装

每个场景节拍都要写清 **此刻穿什么**：

| 错误 | 正确 |
|------|------|
| 只写「去洗澡」 | 写：卧室穿橘短裤 → 脱衣/换浴巾 → 卫生间里穿什么 → 出来穿什么（湿） |
| 假设观众能脑补更衣 | 把「脱/换」写成可见动作 |

**本线底线：** 不裸露。洗澡用 **浴巾 / 泡沫遮挡 / 仍保留卡通短裤** 三选一写死，全程一致。

## 2. 背景：每段点名空间，写清怎么换场

| 错误 | 正确 |
|------|------|
| 不写背景 → 灰底/空镜 | 卧室暖灯双人床 / 瓷砖卫生间花洒 / 走廊地板 |
| 「冲出来」不接空间 | 写清：推开卫生间门 → 经过走廊滴水 → 扑向卧室床 |
| 转场靠模型瞬移 | 用「推门、过道、水渍脚印」做空间链条 |

**公式：** `空间A（穿着1）→ 可见移动 → 空间B（穿着2）`，三段都写进同一条 prompt。

## 3. 道具/身体细节：高潮要「可掉落、可损坏」

例：结尾掀飞时，**头顶小橘子被震掉滚落**——必须明写，否则模型会一直戴稳。

## 4. 表情与动作分开写

- 霸道 = 表情/气场  
- 坏 = 动作（掀飞等）  
不要用「无辜」冲淡霸道（已否决）。

## 5. 时长与细节

- 锚定 **10s**  
- **少写秒表**，多写「必须看清的细节」  
- 宁肯少一句对白，也要保住：更衣、卫生间、过道水渍、掀飞、橘子掉落  

## 6. 垫图

- 双人卧室：`ref_04`  
- 噜噜单人更衣/洗澡：`ref_01`  
- 噜妹霸道：可辅 `lumei_02_暴怒`  
- 换装后若跳戏：先单独生成「浴巾噜噜」「卫生间背景」素材图再图生视频  

## 7. 每条 prompt 自检清单

- [ ] 每个空间都写了名字（卧室/卫生间/走廊）  
- [ ] 每个空间的穿着都写了  
- [ ] 有「推门/走过」等连接，不是瞬移  
- [ ] 高潮有一个夸张物理细节（如橘子震掉）  
- [ ] 无裸露、无第三人

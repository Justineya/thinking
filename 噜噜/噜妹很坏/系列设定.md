# E · 噜妹很坏 · 系列设定

## 定位

| 项 | 内容 |
|----|------|
| 性质 | **双人日常新线**，专写噜妹的「坏」 |
| 调性 | 漫画式欺负、坏得可爱、不真伤害；冷幽默收口 |
| 时长 | 本线试播 **30s** |
| 标签 | `#水豚噜噜` `#噜妹` `#情侣日常` `#打呼` `#内容过于真实` |

## 人设差分（本线）

| 角色 | 本线性格 |
|------|----------|
| **噜妹** | 表面粉嫩无辜，实际坏心眼满满；被吵醒/被打扰就升级报复 |
| **噜噜** | 憨睡、好欺负、挨踹还懵；不反击，只委屈 |

**禁止滑回：** 嘴硬心软升华、吵架和好金句、治愈拥抱收尾。

## 坏的公式

```
噜噜无意识惹到噜妹（打呼/抢被/ thrash）
→ 噜妹先「文明提醒」（拍/戳）
→ 无效
→ 噜妹升级「物理教育」（踹/抢枕/关灯）
→ 她迅速装睡或一脸无辜
```

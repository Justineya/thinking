# E · 噜妹很坏 · 系列设定

## 定位

| 项 | 内容 |
|----|------|
| 性质 | **双人日常新线**，专写噜妹的「坏」 |
| 调性 | 漫画式欺负、坏得可爱、不真伤害；冷幽默收口 |
| 时长 | **锚定 10s**（Seedance 仅 10/15 时选 10；反转须在 7s 前） |
| 标签 | `#水豚噜噜` `#噜妹` `#情侣日常` `#打呼` `#内容过于真实` |

## 人设差分（本线）

| 角色 | 本线性格 |
|------|----------|
| **噜妹** | 表面粉嫩无辜，实际坏心眼满满；被吵醒/被打扰就升级报复 |
| **噜噜** | 憨睡、好欺负、挨踹还懵；不反击，只委屈 |

**禁止滑回：** 嘴硬心软升华、吵架和好金句、治愈拥抱收尾。

## 坏的公式（9800 播复盘：中间慢 → 反转前掉完）

```
1秒内进冲突
→ 一人一句对打（噜妹/噜噜交替，禁止连说、禁止空镜拖）
→ 8秒前必须反转（踹/扯被/装睡）
→ 噜妹脸始终无辜可爱，坏在动作和台词
```

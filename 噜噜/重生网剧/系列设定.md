# B · 重生网剧 · 系列设定

## 定位

| 项 | 内容 |
|----|------|
| 性质 | **独立梗系列**，每集可重置，不必衔接现实炒股线 |
| 调性 | 抖音爽剧/重生网剧 parody，中二旁白 |
| 时长 | 20–30s |
| 标签 | `#重生` `#爽剧` `#炒股` `#搞笑动画` `#水豚噜噜` |
| 片头建议 | 2s 固定：「重生之我在 A 股当韭菜」 |

## ep01 大纲 · 重生回到满仓跌停那天

**钩子（网剧腔旁白）：**  
「重生回到破产前一天，我以为这次能翻盘……」

**中段：** 闪回好兄弟「咱俩股市反着买」→ 噜噜家破人亡 montage（夸张搞笑，不真血腥）

**收尾：** 噜噜睁眼「这剧本我熟」→ 看手机仍满仓跌停 →「……重生没存档啊？」

## 成片（AI 自动合成 v01）

| 文件 | 说明 |
|------|------|
| **成片/ep01_她从来不会说对不起_v01.mp4** | 18s 预览成片（关键帧 + AI 配音 + 字幕） |

> **能力说明**：云端可出「静帧幻灯片 + 配音」预览版；角色动起来、口型、BGM 精修需剪映或图生视频工具。

## 剪映精修版（发布推荐）

1. 打开 **[剪映组装单.md](剪映组装单.md)** 按步骤操作
2. 导入 `关键帧/` 下 5 张图
3. 按 **[配音稿.txt](配音稿.txt)** 生成 5 句配音
4. 导入 **[字幕.srt](字幕.srt)** 或手动加 3 条字幕
5. 导出 `ep01_v01.mp4`，微调后导出 `ep01_v02.mp4`

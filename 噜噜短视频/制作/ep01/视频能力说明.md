# 视频生成能力说明

## 直接回答：有视频模型，但这个云端 Agent 默认没接上

| 能力 | 状态 | 说明 |
|------|------|------|
| **文生图 / 垫图生图** | ✅ 有 | Cursor 内置 `GenerateImage` |
| **图生视频（AI动画）** | ❌ 默认无 | 需可灵 / 即梦 / fal.ai 等 API |
| **静帧拼片 + 配音** | ✅ 有 | `build_video.py` → v01 |
| **静帧 + 运镜动效** | ✅ 有 | `build_video.py --motion kenburns` → v02 |
| **真·角色动画** | 🔑 需 Key | `build_i2v_fal.py` + `FAL_KEY` |

这个环境：**无 GPU、无剪映、无图生视频 API Key**，所以之前只能出「幻灯片版」。

## 业界能做视频的模型（竞品也在用）

| 平台 | 类型 | 适合噜噜 |
|------|------|----------|
| **可灵 Kling** | 图生视频 | ★★★★★ 国内最常用 |

这些都不是「我自带」的——需要你在对应平台有账号/API Key。

## 三条路，按效果排序

### 路线 1 · 真动画（推荐发布）
1. 打开 **可灵** 或 **即梦** App/网页
2. 选「图生视频」，上传 `关键帧/shot01~04.png`
3. 垫图选 `角色延伸包/官方参考/ref_01` 或 `ref_03`
4. 动作 prompt 见 `剪映组装单.md` 第三节
5. 生成 4 段 3–5s 视频 → 剪映拼接 + 组合 A 配音

### 路线 2 · API 自动化（你有 fal Key 时）
```bash
export FAL_KEY=你的key
pip install fal-client
cd 噜噜短视频/制作/ep01
python3 build_i2v_fal.py   # 自动生成 4 段动画
# 再剪映拼配音
```

### 路线 3 · 零成本预览（我已能做）
```bash
python3 build_video.py                    # v01 静帧
python3 build_video.py --motion kenburns  # v02 带运镜
```

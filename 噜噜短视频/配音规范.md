# 噜噜短视频 · 配音规范

> 版本：v1.0 | 日期：2026-07-02

## 核心原则

**噜噜和噜妹各用各的，选定后永远不换。**

| 角色 | 音色 ID | 状态 |
|------|---------|------|
| 噜噜 | `TBD_LULU_V1` | 待首批制作时选定并锁定 |
| 噜妹 | `TBD_LUMEI_V1` | 待首批制作时选定并锁定 |

> 实施说明：制作第 01 条样片时，各生成 2-3 个音色候选，AB 对比后选定，将 ID 填入上表，此后全系列不得更换。

---

## 噜噜音色规格

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 气质 | 偏软、无辜、说话少 | 萌系河马男孩 |
| 语速 | 中等偏快（心虚时） | 心虚时略快、音量偏小 |
| 情绪档位 | 日常 / 心虚 / 小得意 | 底层音色 ID 不变 |
| 旁白 | 默认使用噜噜音色 | 金句/内心独白走此音色 |
| 参考样音 | `samples/lulu_ref_v1.wav` | 待录制 |

### 噜噜台词风格
- 短句为主：「做了！」「那个……」「我不是故意的……」
- 被问话时先答「做了！」再说结果
- 旁白/金句：克制、轻轻的说，0.9 倍速，句号后停顿 0.8s

---

## 噜妹音色规格

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 气质 | 元气、利落、嘴硬 | 河马女孩 |
| 语速 | 中等偏快 | 暴怒时更快 |
| 情绪档位 | 日常 / 暴怒 / 被噎住 / 心软 | 底层音色 ID 不变 |
| 参考样音 | `samples/lumei_ref_v1.wav` | 待录制 |

### 噜妹台词风格
- 暴怒：「你是不是有病啊！」「你根本不在乎！」
- 心软：语气突然放缓，但不道歉
- 嘴硬收尾：「才不是特意买的！」「谁等你了！」

---

## 禁止事项

- 噜噜和噜妹不得共用同一音色
- 不同条/不同集之间不得更换已锁定音色
- 不得临时「试一个新声音」直接进成片
- 噜妹台词不得用噜噜声线，反之亦然

---

## 合成参数（TTS 通用）

| 参数 | 噜噜 | 噜妹 |
|------|------|------|
| 语速 | 0.9-1.0 | 1.0-1.1 |
| 音调 | 中性偏低 | 中性偏高 |
| 停顿 | 句号后 0.8s | 句号后 0.5s |
| BGM 音量 | 人声 30-40% | 同左 |

---

## 锁定流程

1. 制作第 01 条时，各选 2-3 个候选音色
2. AB 对比，选定后更新本文件音色 ID
3. 录制/导出标准样音各 1 条
4. 此后所有配音必须先对比样音再入库

## 噜噜 · 男声（搞怪 / 阳光 / 稍憨）

竞品常见：偏憨、略逗、不凶，适合「搞砸事心虚」的男友感。

### 剪映选音方向

在剪映「文本朗读」中优先试听以下类型（具体名称以剪映当前列表为准）：

| 优先级 | 类型关键词 | 听感目标 |
|--------|-----------|----------|
| P0 | **阳光男孩** / **阳光男声** | 干净、略憨、不油 |
| P0 | **搞怪** / **搞笑** / **趣味男声** | 适合吐槽、心虚、小得意 |
| P1 | **稍憨** / **呆萌** / **少年感** | 软、无辜、说话不长 |
| 避免 | 磁性低音、播音腔、霸道总裁 | 太成熟，不像噜噜 |

### 锁定参数（组合 A）

| 参数 | 值 |
|------|-----|
| 剪映音色 | **阳光男孩**（备选：趣味男声） |
| 语速 | 默认 **1.0**；心虚句 **0.95–1.0**（略慢、小声） |
| 音调 | **+1** |
| 音量 | 心虚句 **85%**；正常 **100%** |
| 气质 | 稍憨、阳光，不凶不油 |
| 旁白/金句 | 默认走噜噜音色；字幕金句可不配音 |

### 台词风格

- 短句：「……我本来可以的。」「那个……」
- 心虚时语速略快、音量偏小
- 禁止霸道、嘴硬、攻击性语气

### 锁定记录

- [x] 组合 A：**阳光男孩** / 趣味男声 → `LULU_V1_A`

## 合成与混音

| 项 | 规格 |
|----|------|
| 工具 | 剪映 → 文本 → 文本朗读 |
| BGM 音量 | 人声的 **30-40%** |

| 多角色 | 噜噜、噜妹分段生成，各用锁定音色，禁止一条里混用 |
| 样音 | 锁定后导出 `samples/lulu_ref_v1.wav`、`samples/lumei_ref_v1.wav` |

## 禁止事项

- 噜噜和噜妹不得共用同一音色
- 不同条/不同集之间不得更换已锁定音色
- 不得临时换音色直接进成片
- 不得用河马/IP 长剧曾用过的音色（若与锁定音色不一致）

---

## 剪映操作步骤（组合 A）

1. 文本 → 新建文本 → 输入台词 → 选中 → **文本朗读**
2. 噜噜句：搜 **阳光男孩**，没有则 **趣味男声** → 生成
3. 噜妹句：搜 **甜美女声**，没有则 **元气少女** → 生成
4. 按上表逐句调语速；噜噜心虚句额外降音量
5. 句间留 **0.3–0.5s** 空白；BGM 音量为人声 **30–40%**
6. 锁定后导出 `samples/lulu_ref_v1.wav`、`samples/lumei_ref_v1.wav` 作对照样音

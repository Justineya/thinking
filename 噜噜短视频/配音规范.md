## 噜噜 · 男声（搞怪 / 阳光 / 稍憨）

竞品常见：偏憨、略逗、不凶，适合「搞砸事心虚」的男友感。

### 剪映选音方向

在剪映「文本朗读」中优先试听以下类型（具体名称以剪映当前列表为准）：

| 优先级 | 类型关键词 | 听感目标 |
|--------|-----------|----------|
| P0 | **阳光男孩** / **阳光男声** | 干净、略憨、不油 |
| P0 | **搞怪** / **搞笑** / **趣味男声** | 适合吐槽、心虚、小得意 |
| P1 | **稍憨** / **呆萌** / **少年感** | 软、无辜、说话不长 |
| 避免 | 磁性低音、播音腔、霸道总裁 | 太成熟，不像噜噜 |

### 参数建议

| 参数 | 值 |
|------|-----|
| 语速 | 1.0（心虚时可 1.05-1.1） |
| 音调 | 默认或略偏高（+1~2） |
| 气质 | 稍憨、阳光，不凶不油 |
| 旁白/金句 | 默认走噜噜音色；字幕金句可不配音 |

### 台词风格

- 短句：「……我本来可以的。」「那个……」
- 心虚时语速略快、音量偏小
- 禁止霸道、嘴硬、攻击性语气

## 噜妹 · 女声（甜美 / 可爱 / 生活日常）

竞品常见：女友感、生活化、凶时利落但不播音腔。

### 剪映选音方向

| 优先级 | 类型关键词 | 听感目标 |
|--------|-----------|----------|
| P0 | **甜美** / **甜美女声** | 情侣日常基础声线 |
| P0 | **可爱** / **少女** | 元气、嘴硬时不违和 |
| P1 | **生活日常** / **邻家** / **贴心女生** | 真实感、像身边女友 |
| 避免 | 知性御姐、新闻播报、过于萝莉尖音 | 不像女友或太做作 |

### 参数建议

| 参数 | 值 |
|------|-----|
| 语速 | 1.0-1.1（暴怒时可 1.15-1.2） |
| 音调 | 默认 |
| 情绪档位 | 日常 / 暴怒 / 被噎住 / 嘴硬 — **音色 ID 不变** |

### 台词风格

- 暴怒：「你再碰厨房试试！」「连牛排都能煎焦？！」
- 嘴硬：「买一送一清库存，别多想。」
- 禁止真恶毒、纯泼妇无限骂

## 合成与混音

| 项 | 规格 |
|----|------|
| 工具 | 剪映 → 文本 → 文本朗读 |
| BGM 音量 | 人声的 **30-40%** |
| 句间停顿 | 噜噜句号后 0.5-0.8s；噜妹句号后 0.3-0.5s |
| 多角色 | 噜噜、噜妹分段生成，各用锁定音色，禁止一条里混用 |
| 样音 | 锁定后导出 `samples/lulu_ref_v1.wav`、`samples/lumei_ref_v1.wav` |

---

## 禁止事项

- 噜噜和噜妹不得共用同一音色
- 不同条/不同集之间不得更换已锁定音色
- 不得临时换音色直接进成片
- 不得用河马/IP 长剧曾用过的音色（若与锁定音色不一致）

---

## 锁定流程

1. 打开剪映，按上表方向各试听 2-3 个男声 / 女声
2. 用第01条台词片段 AB 对比（噜噜念心虚句、噜妹念骂人+嘴硬句）
3. 选定后把剪映音色全名写入本文件「音色 ID」栏
4. 导出标准样音，此后每条必须先对比样音再入库

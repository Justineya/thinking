## 生成流程

1. 优先使用本仓库 `角色延伸包/` 内已生成 PNG 参考图
2. 缺档位时用 Cursor 内置生图补全（不必即梦/豆包）
3. 基础设定图 + 情绪描述 + `生成锚点.md` 后缀 → 如需补图
4. 人工确认与 IP 一致 → `approved: true`
5. 写入 `素材库.json` 后送入视频工具

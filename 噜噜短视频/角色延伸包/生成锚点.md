## 噜噜 Prompt 后缀

```
same character as reference, cute capybara boy, warm mango caramel color,
round chubby body, small orange on head, gentle goofy smile,
soft 3D cartoon style, healing anime aesthetic, clean simple lines
```

## 噜妹 Prompt 后缀

```
same character as reference, cute female capybara girl, warm pastel caramel color,
slightly slimmer body, expressive face, kawaii girlfriend style,
soft 3D cartoon style, healing anime aesthetic
```

## 禁止词（负向 prompt）

```
hippo, horse, realistic animal, ugly, deformed, extra limbs, tail on capybara,
duplicate character, dark horror, aggressive, sharp teeth, macaron plastic toy
```

## 生成流程

1. 用白底水豚噜噜参考图（见 `形象规范.md`）
2. 选情绪档位 + 此后缀 → 即梦/豆包生图
3. 确认：水豚、暖色、噜噜有头顶橘子
4. `approved: true` 后写入 `素材库.json`
5. 再送入视频工具

> 版本：v1.0 | 日期：2026-07-02  
> **短视频角色形象与竞品「水豚噜噜」保持一致**，不复用手册中的河马造型。

## 定位说明

| 项目 | 形象来源 |
|------|----------|
| 噜噜短视频 | **水豚噜噜**（竞品同款视觉体系） |
| 噜噜系列长剧（手册） | 河马马卡龙造型（长剧专用，短视频不混用） |

短视频观众认知的是**水豚噜噜**生态，形象对齐竞品可降低识别成本；差异化放在**内容调性**（嘴硬心软）和**制作品质**（双音色锁定、质检），而非另起造型。

## 噜噜（男友 · 水豚男孩）

### 视觉铁律

| 特征 | 规格 |
|------|------|
| 物种 | **水豚**（capybara），不是河马 |
| 配色 | 暖色调、芒果/焦糖色系，圆润饱满 |
| 标志 | **头顶一颗小橘子**（核心记忆点，不可省略） |
| 体型 | 矮胖、软乎乎、无尾巴或极短尾 |
| 表情 | 淡然、呆萌、漏齿笑；心虚时耳朵/腮帮微垂 |
| 质感 | 3D 卡通 / 治愈系动画，偏《平头哥》少年篇二创风格 |
| 禁止 | 河马、马卡龙粉蓝、盲盒塑料感、无橘子 |

### 生图 Prompt 锚点

```
cute capybara character, warm mango caramel color, round chubby body,
small orange fruit on top of head, gentle goofy smile, soft 3D cartoon style,
healing anime aesthetic, simple clean lines, same character as reference
```

### 参考来源

- 动画《平头哥》少年篇 · 水豚噜噜官方设定
- 抖音 #水豚噜噜 高播二创账号的正面/侧面参考图
- 生图前准备：**白底正面图 + 白底背面图**（水豚无尾巴，需背面参考防 AI 乱加尾）

## 噜妹（女友 · 水豚女孩）

### 视觉铁律

| 特征 | 规格 |
|------|------|
| 物种 | **水豚**（与噜噜同物种配对） |
| 配色 | 同暖色系，可略浅或加腮红强调少女感 |
| 标志 | 可无橘子，或橘子饰品（发夹/小挂件），**不与噜噜头顶橘子完全相同** |
| 体型 | 比噜噜略瘦一圈，更有少女感 |
| 表情 | 表情丰富：元气、暴怒、嘴硬心软 |
| 禁止 | 河马、人类女孩、其他动物物种 |

### 生图 Prompt 锚点

```
cute female capybara character, warm pastel caramel color, slightly slimmer body,
expressive face, kawaii girlfriend aesthetic, soft 3D cartoon style,
healing anime aesthetic, same character as reference
```

## 与竞品的一致性检查

每条成片入库前核对：

- [ ] 是水豚，不是河马或其他动物
- [ ] 噜噜头顶有橘子（或明确符合官方设定）
- [ ] 暖色圆润风格，不是冷色写实
- [ ] 噜噜、噜妹同条视频内风格统一
- [ ] 与手册河马资产未混用

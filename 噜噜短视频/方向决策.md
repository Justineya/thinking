# 噜噜垂类 · 方向决策

> 决策日期：2026-07-02。大方向已锁定：**继续噜噜垂类**。本文档确定子方向。

## 决策结论

### P0 主线：20-30s 嘴硬心软微剧情

| 项 | 决策 |
|----|------|
| 时长 | 20-30 秒 |
| 结构 | 钩子 3s → 铺垫 12-18s → 反转 4-6s |
| 选题 | 具体行为细节背后的「在乎」 |
| 调性 | 有冲突的治愈 — 不是纯搞笑，不是纯甜 |
| 表情 | 适度夸张（市场）+ 微表情细节（手册） |
| 标签 | #情侣日常 #内容过于真实 #治愈系 #轻漫计划 |
| 更新 | 周更 2-3 条 |

**数据依据**：
- 水豚噜噜/一二布布主线均为 15-60s 叙事，非 8s 金句
- 「无效安慰」「骂完默默关心」类情感条互动率高于纯搞笑
- 15s 三幕结构（钩子→铺垫→反转）为行业验证最优解
- 噜妹「嘴硬心软」人设与市场需求交集最大

## 差异化策略（vs 水豚噜噜）

```
水豚噜噜 = 搞笑 + 食物和好 + 水豚形象
河马噜噜 = 在乎 + 行为揭示 + 马卡龙河马 + 制作品质
```

### 三条差异化铁律

1. **冲突来自在乎，不来自恶意** — 所有矛盾底层是「在乎」
2. **和解靠行为，不靠道歉** — 「她从来不会说对不起，但会记得我爱喝什么」
3. **品质即壁垒** — 双音色 + 延伸包 + 质检，做竞品做不到的精品

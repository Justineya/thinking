# 噜噜垂类 · 方向决策

> 决策日期：2026-07-02。大方向已锁定：**继续噜噜垂类**。本文档确定子方向。

## 决策结论

### P0 主线（2026-07 调整）

| 项 | 决策 |
|----|------|
| 主结构 | **不再每条套用「骂→藏爱→金句」** |
| 子方向 A | **记仇本系** — 好笑揭穿、罪证流水账、吐槽收束 |
| 子方向 B | **各玩各的系** — 低压陪伴、少台词、无硬反转 |
| 暖心嘴硬线 | 保留为 **少数条**（如 ep01），非默认模板 |
| 表情 | 适度夸张（市场）+ 微表情细节（手册） |
| 标签 | #情侣日常 #内容过于真实 #治愈系 #轻漫计划 |
| 更新 | 周更 2-3 条 |

**数据依据**：
- 水豚噜噜/一二布布主线均为 15-60s 叙事，非 8s 金句
- 「无效安慰」「骂完默默关心」类情感条互动率高于纯搞笑
- 15s 三幕结构（钩子→铺垫→反转）为行业验证最优解
- 噜妹「嘴硬心软」人设与市场需求交集最大

### P1 辅线：8-10s 金句引流

| 项 | 决策 |
|----|------|
| 用途 | 测试选题、引流、非账号主线 |
| 来源 | 手册金句库 + 竞品验证句式 |
| 频率 | 每月 1-2 条，不占用主线产能 |

### 不做

| 方向 | 原因 |
|------|------|
| 纯搞笑互怼 | 水豚噜噜已占领 + 偏离噜噜人设 |
| AI 仿真人爽剧 | 已否决 — IP 不匹配 |
| 纯表情包无剧情 | 反向样本验证无效 |
| 沙雕量产 | 同质化红海 |

## 差异化策略（vs 水豚噜噜二创号）

```
形象：与竞品一致（水豚噜噜 + 噜妹）
内容：嘴硬心软情感（非纯搞笑）
配音：剪映锁定双音色（竞品普遍不锁）
品质：延伸包 + 逐帧质检
```

### 四条铁律

1. **形象对齐竞品** — 水豚、暖色、噜噜头顶橘子（见 `形象规范.md`）
2. **冲突来自在乎** — 所有矛盾底层是「在乎」
3. **配音锁定** — 噜噜：搞怪/阳光/稍憨；噜妹：甜美/可爱/生活日常（剪映）
4. **品质即壁垒** — 双音色 + 延伸包 + 质检

# 噜噜短视频 · 成片质检清单

> 每条视频交付前必须逐项勾选。A 级一票否决，B 级需修复，C 级可接受。

## A 级 — 一票否决（出现即打回重生成）

- [ ] 角色身体变形、多手多脚、面部崩坏
- [ ] 场景图混入多余角色 / 角色重复出现
- [ ] 物体凭空出现或消失（逻辑不通）
- [ ] 角色身份混淆（噜噜噜妹搞反、配色偏离马卡龙系）
- [ ] 噜噜表现出嘴硬/攻击性（违背人设）
- [ ] 噜妹表现出真伤害噜噜（违背人设）

## B 级 — 需修复

- [ ] 噜噜/噜妹配音用错角色音色
- [ ] 表情与脚本情绪不符（该心虚却得意）
- [ ] 光影与环境不匹配
- [ ] 旁白/金句与画面节奏错位
- [ ] 噜妹暴怒「没炸到位」或「没噎住」
- [ ] 结尾太甜，没有「嘴硬」余味

## C 级 — 优化项（可接受但不理想）

- [ ] 微表情不够细腻
- [ ] 塑料质感反光过强/过弱
- [ ] BGM 与人声比例欠佳
- [ ] 字幕时机略偏

---

## 配音检查

- [ ] 噜噜台词/旁白使用锁定噜噜音色
- [ ] 噜妹台词使用锁定噜妹音色
- [ ] 语速、情绪与标准样音对齐
- [ ] 文本与脚本完全一致

## 叙事检查

- [ ] 开头 3 秒有钩子
- [ ] 至少 1 次反转
- [ ] 金句从具体行为出发（如有）
- [ ] 冲突来自「在乎」非「恶意」

## 流程铁律

1. 每条生成 ≥2 版本，选最优过检
2. 20-30s 视频逐帧检查
3. 质检结果写入脚本 `qa_notes` 字段
4. 高频 bug 记入 [bug-log.md](bug-log.md)

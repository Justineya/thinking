# 噜噜短视频项目

> 市场驱动的噜噜垂类短视频项目。方向已锁定：**情侣萌系动画 IP**，用竞品数据定打法，用制作规范保品质。

## 战略定位

| 已锁定 | 说明 |
|--------|------|
| IP | **水豚噜噜 + 噜妹**（形象对标竞品，见 [形象规范.md](形象规范.md)） |
| 赛道 | 情侣萌系动画垂类（#水豚噜噜 生态） |
| 主线 | **18-20s 嘴硬心软微剧情** |
| 辅线 | 8-10s 金句短片（引流用） |
| 差异化 | 内容「在乎型」+ 双音色锁定 + 质检（形象与竞品一致） |
| 配音 | 剪映：噜噜=搞怪/阳光/稍憨男声；噜妹=甜美/可爱/生活日常女声 |

## 制作流程

```
选题（金句库/竞品公式）→ 写 .cvs 分镜 → 选定延伸图 → 合成配音 → AI 生成 ≥2 版 → 逐帧质检 → 交付
```

## 子方向决策摘要

**P0 主线：20-30s 嘴硬心软微剧情**
- 结构：钩子 3s → 铺垫 12-18s → 反转 4-6s
- 选题：具体行为细节背后的「在乎」
- 标签：#情侣日常 #内容过于真实 #治愈系 #轻漫计划

**P1 辅线：8-10s 金句引流**
- 用于测试选题、引流，不做账号主线

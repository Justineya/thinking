## Tier 1 — 直接竞品（情侣萌系动画）

### #1 水豚噜噜（头部二创生态）

| 维度 | 分析 |
|------|------|
| 基础数据 | 百万级粉丝生态；单条「无效安慰 vs 有效安慰」等高互动；标签 #水豚噜噜 #轻漫计划 |
| 内容类型 | **情侣搞笑日常**为主：吵架、哄女友、消费观、睡前流程 |
| 时长 | 15-60s 为主，极少 8s |
| 前 3 秒钩子 | 冲突画面/对话（「你又怎么了？」）或反差标题 |
| 结构 | 冲突 → 噜噜犯蠢/被怼 → 反转和好（烧烤/奶茶） |
| 视觉 | 圆润水豚，表情偏夸张；AI 二创一致性参差 |
| 配音 | 多音色混用；偏搞笑语气 |
| 爆款 vs 平庸 | 爆的：**具体生活场景+真实感**；平的：纯表情包无剧情 |

**对噜噜启示**：选题频率最高的是「吵架→和好」「无效安慰」；但纯搞笑已被占领。

## 竞品对比总结

| 维度 | 水豚噜噜 | 一二布布 | 噜噜应做 |
|------|----------|----------|----------|
| 主调性 | 搞笑互怼 | 治愈甜蜜 | **嘴硬心软情感** |
| 时长 | 15-60s | 15-45s | **20-30s** |
| 钩子 | 冲突/吵架 | 可爱日常 | **行为细节悬念** |
| 反转 | 食物和好 | 温暖收尾 | **默默在乎的揭示** |
| 表情 | 偏夸张 | 软萌 | **适度夸张**（市场+手册折中） |
| 品质 | 参差 | 较统一 | **精品壁垒** |

# 噜噜短视频 · 创作规范

> 市场数据定形式，创作手册定人设。本文档融合两者。

## 一、内容规格（P0 主线）

| 项 | 规格 |
|----|------|
| 时长 | 20-30 秒 |
| 结构 | 钩子 3s → 铺垫 12-18s → 反转 4-6s |
| 镜头 | 3-5 个 |
| 反转 | 至少 1 次，推荐 2 次 |
| 调性 | 嘴硬心软 — 有冲突的治愈 |

## 二、脚本写法

### 先写反转，再反推开头

1. 确定本条「行为揭示」是什么（冰箱、门缝、灯亮…）
2. 写反转镜头
3. 反推铺垫需要什么冲突
4. 写 3 秒钩子

### 钩子库（前 3 秒）

| 类型 | 示例 |
|------|------|
| 冲突对话 | 「你根本不在乎！」 |
| 动作悬念 | 噜妹摔门而出 |
| 行为异常 | 噜噜缩脖子 + 噜妹瞪眼 |
| 反常识 | 「她骂了我一整天，然后……」 |

### 金句规则（来自手册，市场验证）

- 从**具体行为细节**出发
- 不用文学修辞硬造
- 正确：「她从来不会说对不起。但她会记得我爱喝什么。」
- 错误：「她是唯一一个愿意留下来的人。」

## 三、人设铁律（不可违反）

### 噜噜
- 心虚想弥补，不是嘴硬
- 说话少，多用表情和动作
- 禁止攻击性或恶意行为

### 噜妹
- 暴怒要「炸到位再被噎住」
- 凶底下有在乎；骂完会默默做事
- 禁止真伤害噜噜

### 两人关系
- 吵吵闹闹但离不开
- 矛盾永远来自「在乎」

## 四、视觉规范（水豚噜噜 · 对标竞品）

> 详见 [形象规范.md](形象规范.md)。**短视频用水豚造型，不用手册河马造型。**

- **噜噜**：水豚、暖芒果色、**头顶橘子**、圆润呆萌
- **噜妹**：水豚女友、同暖色系、略瘦、表情丰富
- 场景图**不含角色**（角色单独合成）
- 表情：**适度夸张** — 与竞品情侣动画一致

### 噜噜角色风格词

```
chibi 3D capybara, bright golden yellow body, large orange snout patch,
blue glossy eyes, one front tooth, orange on head, orange shorts, 水豚噜噜 style
```

### 噜妹角色风格词

```
chibi 3D capybara, golden yellow body, big pink bow, orange on head,
pink dress, blue eyes, same style as Lulu reference
```

### 场景风格词

```
cozy interior, macaron color palette, soft warm lighting,
picture book illustration style, pastel colors, no characters,
gentle ambient light, comfortable atmosphere
```

## 五、情感镜头铁律

- **一个微动作 + 一个光源 + 一次慢推**
- 多动作 = 抽搐感
- 负向词：`no blink, no head turn, mouth still`（需要静时）

## 六、发布策略

| 项 | 建议 |
|----|------|
| 标签 | #情侣日常 #内容过于真实 #治愈系 #轻漫计划 |
| 时段 | 21:00-23:00（情感类） |
| 合集 | 按主题分系列 |
| 互动 | 结尾提问：「你们家也这样吗？」 |
| 频率 | 周更 2-3 条 |

## 七、.cvs 脚本字段

| 字段 | 说明 |
|------|------|
| episode_id | 集号 |
| title | 标题 |
| duration | 总时长 |
| shot_no | 镜头序号 |
| duration_shot | 镜头时长 |
| scene_asset | 场景素材 ID（见素材库.json） |
| char_ref_lulu | 噜噜延伸图 ID |
| char_ref_lumei | 噜妹延伸图 ID |
| action | 角色动作 |
| expression | 表情描述 |
| dialogue_lulu | 噜噜台词 |
| dialogue_lumei | 噜妹台词 |
| narration | 旁白/金句（噜噜音色） |
| voice_lulu | 配音规范版本号 |
| voice_lumei | 配音规范版本号 |
| sfx | 音效 |
| qa_notes | 质检记录 |

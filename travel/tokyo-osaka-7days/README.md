# 东京 · 大阪七日游（网页版）

含大阪环球影城，不含迪士尼。

## 在线地址（GitHub Pages）

静态站已推到 **`gh-pages`** 分支。请你本地打开一次仓库设置完成发布：

1. 打开 https://github.com/Justineya/thinking/settings/pages  
2. **Build and deployment → Source** 选 **Deploy from a branch**  
3. Branch 选 **`gh-pages`** / **`/`（root）** → Save  

约 1～2 分钟后访问：

**https://justineya.github.io/thinking/**

（也可在 Source 选 GitHub Actions，用 `.github/workflows/deploy-tokyo-osaka.yml` 自动部署。）

## 本地打开

用浏览器直接打开 `index.html`，或：

```bash
python3 -m http.server 8765
```

访问 `http://localhost:8765`。

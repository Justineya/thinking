Itinerary

逐日行程 · 吃与订

每天两到三个主点，并附餐厅与当日相关预订入口。

DAY 01TOKYO

下町初印象

入住浅草、上野或秋叶原。机场线可坐京成 Skyliner 到上野，手机钱包开通 Suica。

  • 雷门 → 仲见世通 → 浅草寺
  • 傍晚晴空塔看灯
  • 晚饭拉面或烧肉

EAT

  • 一兰拉面 · 浅草店 豚骨拉面，单人隔间，人均约 ¥1,200。浅草站步行 1 分钟。
    大众点评 DP 店铺官网
  • 浅草今半 · 寿喜烧（备选） 想吃老东京寿喜烧可订位；人均偏高，适合第一顿「迎接」。
    大众点评搜索 DP
订东京浅草酒店
DAY 02TOKYO

神社与潮流街区

明治神宫早去人少。竹下通可匆匆穿过，表参道适合慢慢走。

  • 明治神宫 → 原宿 → 表参道
  • 涩谷十字路口；SHIBUYA SKY 需预约
  • 晚间新宿东口逛一圈即可

EAT

  • 银座小野寺 · 表参道本店（回转寿司） 原宿/表参道午饭；取号排队，人均约 ¥3,000–4,000。
    大众点评搜索 DP
  • 一兰 / Afuri · 涩谷（晚饭备选） 逛完涩谷吃一碗拉面；Afuri 柚子盐拉面更清爽。
    大众点评 · 一兰涩谷 大众点评 · Afuri
订 SHIBUYA SKY
DAY 03TOKYO

丰洲与台场（不去迪士尼）

用一天做轻松主题，把体力留给大阪环球。

  • 早：丰洲市场吃寿司
  • 午后：teamLab Planets（提前购票）或台场海滨
  • 晚：整理行李，预订次日新干线指定席

EAT

  • 寿司大 · 丰洲市场 传奇板前寿司，早到排队；店长推荐套餐约 ¥4,000+。也可选市场内其他寿司店避峰。
    大众点评 · 寿司大 DP
  • 根室花丸 · 回转寿司（备选） 不想排寿司大时，东京站 KITTE 等分店性价比高。
    大众点评搜索 DP
订 teamLab Planets 订次日新干线
DAY 04TOKYO → OSAKA

南下关西

东京站或品川站搭东海道新干线至新大阪，约两个半小时。单程约一万四千日元。

  • 上午：皇居外苑或银座轻逛
  • 下午：入住心斋桥 / 难波 / 本町
  • 道顿堀、固力果跑跑人、章鱼烧

EAT

  • 千房 · 道顿堀支店 大阪烧老字号，综合大阪烧约 ¥2,200；人多可错峰。
    大众点评 · 千房 DP 千房官网
  • 元祖串かつ だるま · 道顿堀店 串炸，禁止二次蘸酱；人均约 ¥1,500–2,500。
    大众点评搜索 DP 达摩官网
订大阪难波酒店 飞猪新干线
DAY 05KYOTO

京都一日

从大阪坐 JR 快速约三十分钟到京都。巴士易堵，能走路就走路。

  • 伏见稻荷大社（尽早）
  • 清水寺 → 二年坂三年坂
  • 祇园散步；晚饭可回大阪吃更热闹的

EAT

  • 清水寺周边 · 米饭豆腐 / 抹茶甜品 二年坂、三年坂小吃即可，别塞正餐；晚饭回道顿堀更痛快。
    大众点评 · 清水豆腐
  • 回大阪晚饭 · 神座 / 金龙拉面 道顿堀白菜酱油面或金龙，夜宵友好。
    大众点评 · 神座 大众点评 · 金龙

全日环球影城

这天只办一件事。难波 / 心斋桥坐地铁到 Universal City。

  • 开园前 60～90 分钟到达
  • 优先任天堂世界、哈利波特、飞天翼龙
  • 出园回心斋桥吃串炸或大阪烧

EAT

  • 园内简餐 + 出园串炸 园内贵且排队；出园再去达摩或千房更划算。
    大众点评 · 串炸达摩

DAY 07NARA · DEPART

奈良半日与返程

近铁到奈良。关西机场预留起飞前 2.5～3 小时出门。

  • 东大寺 → 奈良公园喂鹿
  • 回大阪取行李，药妆手信补购
  • 南海电铁或 JR 空港急行列关西空港

  • 奈良 · 柿叶寿司 / 葛切 东大寺周边轻食即可，别吃太撑赶飞机。

Universal Studios Japan

环球影城备忘

任天堂世界需分区入场。想稳进，买带 Area Timed Entry / SUPER NINTENDO WORLD 字样的 Express；入园前装好官方 App 并登记门票。

携程购票 飞猪购票
  • 票务组合 Studio Pass 入园票 + Express Pass（建议含任天堂预约）。Power-Up Band 可选。
  • App 必做 2026 年起同日分区票多在官方 App 领取；进园前完成登记，别在门口现装。
  • 游玩顺序 马里奥赛车 / 咚奇刚矿车 → 哈利波特禁忌之旅 → 飞天翼龙或小黄人。
  • 体力安排 D5 京都回来早点睡；D6 不塞其他景点。

Essentials

实用与预算

出行前把交通卡、预约和行李寄送想清楚，比多排两个景点更重要。

交通

手机 Suica / ICOCA。东京至新大阪单买指定席；市内地铁巴士刷卡即可。

预约

teamLab、SHIBUYA SKY、USJ 门票与 Express 尽量提前。人气餐厅可用大众点评看排队，部分店需电话订位。

行李

D4 可用宅急便把大件寄到大阪酒店，人只带隔夜包坐新干线。

礼仪

电车不打电话，神社内保持安静，垃圾桶很少——垃圾随身带走。

预算粗算（不含机票）： 住宿每晚约 ¥12,000–20,000，餐饮每天 ¥5,000–8,000，新干线单程约 ¥14,000，USJ 门票 + Express 另计。七天一人约 ¥8–13 万（含乐园）。

周六 · 吃逛主场

西关街巷 + 沙面 + 一顿正经粤菜

全天打车串联

09:00

早茶（茶楼任选，或大同酒家）

两人点 5–6 笼即可：虾饺、烧卖、叉烧包、肠粉、流沙包、凤爪，再加一壶茶。

必点：虾饺 / 烧卖 / 肠粉 酒店打车直达

热门店建议提前预约；迟到就近找口碑茶楼也完全成立。

10:45

永庆坊（必逛）

慢慢走西关巷子、拍照、进小店。上下九可贴边走一段，人太多就撤。

必玩：骑楼街拍 / 小店闲逛 可加：双皮奶 / 糖水
13:00

惠食佳 · 正餐（老婆精选 · 优先）

黑珍珠粤菜，稳、正宗，适合作为「广州第一顿正经菜」。若订不到午市，改晚市，中午沙面附近简餐。

必点见下方餐厅卡 永庆坊打车前往
替换：更想精致仪式感 → 换成侨美食家；惠食佳改周日或放弃。
15:00

沙面（必逛）

树荫、洋房、江边散步。可顺路看石室圣心大教堂外观。累了就找家咖啡/甜品坐着。

必玩：江边慢走 / 建筑拍照
可选加站：去沙面前若还有 45 分钟，可进陈家祠看木雕砖雕。
17:30

回天河歇一会

回酒店洗澡休息。夏天这样安排最舒服，晚上再出动。

19:30

花城广场夜景 + 小吃夜宵

看灯、散步、拍广州塔外观。正餐已在中午解决，晚上吃牛杂、肠粉、糖水即可。

必玩：花城夜景 夜宵：牛杂 / 糖水
升级：想坐船就订珠江夜游；周五没看夜景的话，这晚优先。

周六 · 吃货加强

正餐拉满

09:00

大同酒家 · 早茶（老婆精选）

老字号酒楼氛围，适合体验「广州早茶该有的热闹」。点传统点心，别点太满，晚上还有正餐。

必点：虾饺、叉烧包、肠粉、蛋挞

永庆坊慢逛 + 路边补甜

15:30

必点见下方餐厅卡 预留堵车时间
备选：订不到侨美食家 → 改惠食佳晚市，逻辑不变。
20:30

饭后花城散步消食

不强制夜游。走一走看灯，想吃甜再来份双皮奶收尾。

MUST SEE

景点必玩

第一次来，这四个点足够。每个只抓一件「必做的小事」，别贪多。

夜景首选

花城广场 / 广州塔

现代广州的门面。住天河最方便，周五或周六晚去一次就够。

  • 必玩：沿花城大道走到能看见广州塔的位置拍一张双人照
  • 必玩：海心沙方向走一段，感受江风与灯光
  • 可选：上塔（周日有空再决定，看云层和排队）
老城氛围

永庆坊

改造后的西关，好逛好拍，第一次不会迷路崩溃。

  • 必玩：沿主街慢慢走完，进 1–2 家小店
  • 必玩：找一段骑楼或砖墙拍生活感照片
  • 可选：上下九只走边缘，不硬撑
散步胜地

沙面

树多、建筑美、适合两个人并肩走，不需要攻略。

  • 必玩：沿岛外圈走半圈以上
  • 必玩：找长椅或咖啡馆坐 20 分钟
  • 可选：石室圣心大教堂外观
可选加分

珠江夜游 · 陈家祠

时间多再加。夜游适合方案 C；陈家祠适合插在永庆坊去沙面的路上。

  • 珠江夜游必玩：选夜场，提前订票，看两岸灯带即可，不必纠结哪条船
  • 陈家祠必玩：进门看中轴建筑与木雕，1 小时内结束

MUST ORDER

餐厅必点

老婆选的三家都对。建议：黑珍珠正餐二选一为主，大同更适合早茶/午市。

黑珍珠 优先正餐

惠食佳

稳、正宗、适合当广州第一顿正经粤菜。方案 A / C 首选。

  • 必点：脆皮乳鸽（或招牌鸽类）
  • 必点：时令海鲜或避风塘风格炒菜（以当日菜单为准）
  • 必点：一例老火汤 + 一道清淡时蔬
  • 可加：经典粤式小炒 / 煲仔类，两人总菜量控制在 3–4 道
怎么排：周六午市或晚市订一顿即可；与侨美食家二选一，不必两顿都上。
黑珍珠 仪式感正餐

侨美食家

更偏精致与安静，适合想吃得讲究一点的晚上。方案 B 主打。

  • 必点：招牌招牌菜 / 厨师推荐（到店先问今日必点）
  • 必点：一只禽类或烧腊类硬菜
  • 必点：一道汤、一道青菜，平衡油润
  • 可加：点心或甜品收尾，但若中午已早茶则少点淀粉
怎么排：当「升级替代」用；订到就周六晚吃，订不到回流惠食佳。
老字号氛围 早茶更合适

大同酒家

传统酒楼感强，热闹、经典，周五晚到不建议硬赶，留给早茶最好。

  • 必点：虾饺、烧卖、叉烧包
  • 必点：肠粉（或鸳鸯肠粉）
  • 必点：蛋挞 / 流沙包，甜咸搭配
  • 可加：凤爪、排骨，两人点到微撑就停
怎么排：方案 B 周六早茶首选；方案 A 也可拿它当早茶店，正餐仍留给黑珍珠。

STREET FOOD

街头补完清单

正餐之外，用这些把「广州味道」补齐。遇到就吃，排太久就换下一家。

咸口

  • 牛杂
  • 煲仔饭
  • 云吞面
  • 烧腊简餐

甜口

  • 双皮奶
  • 姜撞奶
  • 杨枝甘露 / 糖水

吃逛原则

  • 正餐 1–2 顿粤菜就够
  • 排队超 30 分钟换店
  • 段与段之间打车，街区内走路

NOTES

出门前记一下

预约

惠食佳 / 侨美食家周末难订，尽快定一顿。大同早茶尽量订或早到。

打车

高德 / 滴滴即可。永庆坊 → 沙面很近；去花城预留高峰缓冲。

天气与穿着

薄外套防空调，折叠伞，舒适走路鞋。室内外温差大。

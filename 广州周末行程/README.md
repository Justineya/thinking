# 广州周末 · 两人吃逛行程

一页式行程表，含三套方案切换、景点必玩与餐厅必点。

## 手机打开（推荐）

仓库是私有的，在线链接打不开图片。请用下面任一方式：

### 方法一：单文件（最省事）

打开 / 发送这个文件到手机：

- `广州周末-手机打开.html`（约 1.8MB，图片已内嵌）

步骤：
1. 发到微信「文件传输助手」或隔空投送 / AirDrop
2. 用 **Safari / Chrome / 系统浏览器** 打开（不要用微信内置预览硬看大文件）
3. 可离线查看，不依赖网络

### 方法二：压缩包

打开 `广州周末行程-手机包.zip`，解压后：

- 优先打开里面的 `广州周末-手机打开.html`
- 或保持 `index.html` 与 `images` 在同一文件夹再打开

> 不要只单独保存 `index.html`，否则相对路径图片会全部丢失。

## 电脑打开

```bash
open 广州周末行程/index.html
# 或
python3 -m http.server 8765
```

浏览器访问 `http://localhost:8765`。

## 内容说明

- **方案 A**：稳妥吃逛（推荐）— 惠食佳正餐
- **方案 B**：吃货加强 — 大同早茶 + 侨美食家
- **方案 C**：夜景慢游 — 花城 / 珠江夜游优先

住地：天河体育中心附近；出行：打车为主。

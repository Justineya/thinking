# 广州周末 · 两人吃逛行程

一页式行程表（HTML），含三套方案切换、景点必玩与餐厅必点。

## 打开方式

用浏览器直接打开：

```bash
open 广州周末行程/index.html
```

或在本目录起一个本地服务：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765`。

## 内容说明

- **方案 A**：稳妥吃逛（推荐）— 惠食佳正餐
- **方案 B**：吃货加强 — 大同早茶 + 侨美食家
- **方案 C**：夜景慢游 — 花城 / 珠江夜游优先

住地按天河体育中心附近；出行按打车为主。

# 谨记 · 炒股坑本

本地笔记本：专门记炒股踩过的坑，并强迫你把「下次铁律」钉在开盘前。

> 不是荐股工具。是给你自己留的羞耻账本。

## 它怎么逼你谨记

1. **我说你记**：甩一段今天怎么翻的车 → 抽出铁律 → 盖章钉墙
2. **首页就是铁律墙**，不是仪表盘
3. **再犯一次**会加重痛感、重新钉墙
4. **开盘前诵读**：逐条点「我谨记了」

也可以直接跟 Cursor 说经历，让助手帮你写入坑本。

## 启动

```bash
cd trade-pit
bash start.sh
```

Windows 可双击 `start.bat`。

浏览器打开：http://127.0.0.1:8766/

## 数据结构

每条坑包含：

- 标题 / 发生了什么 / 代价
- **下次铁律**（核心）
- 痛感 1–5、标签、是否钉墙
- 再犯次数、诵读确认次数

数据存在 `trade-pit/data/pits.db`（本地 SQLite）。

# 陈氏家族（电脑 / 手机两用 · 后台体验版）

规则和公式记载见 [DATA.md](./DATA.md)，下一版动效/产业链见 [PRD.md](./PRD.md)。

同一套页面：手机竖屏底栏；电脑宽屏左侧导航、右侧履历。空格暂停，Esc 关掉履历。

本版先当后台包：顶栏可以随便加灵感，把商店、省级入学、网红、高净值都点一遍。

- 家族谱：圆头像 + 月流水（上学显示负学费）
- 升学弹窗：乡镇 / 县城 / 市级花现金，省级花灵感
- 灵感页：换现金、四维、全员津贴；并展示职业底薪和工资公式
- 记事页：随机事件 / 升职 / 兑换写入 `eventLog`
- 产业页：买铺收租（解锁链还在 P0）
- 点头像：履历里有职级和工龄
- 开局随机单人穷种子，顶栏「重开」再抽一条命

```bash
cd family && python3 -m http.server 8765
```

# 家族谱 · 人生模拟（横版原型）

横版家族树。头像很小；**到年龄自动弹窗**，用抽卡决定学校 / 对象 / 工作。

## 本地打开

```bash
cd family
python3 -m http.server 8765
```

手机请横过来。浏览器访问 http://localhost:8765（不要用 `file://`）。

## 怎么玩

- 主界面只有家族谱：小头像 + 年龄 + 月收入
- 成年顺序固定：**先抽工作 → 再抽恋爱 → 谈满 6 个月才结婚入谱**
- 满 6 / 12 / 15 / 18 岁学生会抽升学（N 普通，SSR 破格名校）
- 结婚满一年会问要不要生孩子（每对最多 2 个）
- 3 秒 = 1 个月

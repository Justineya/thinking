# 家族谱 · 人生模拟（横版原型）

左侧成员栏 + 中间家谱 + 右侧履历。到年龄弹窗：**正常列表选择**，破格选项花代币。

## 打开

```bash
cd family
python3 -m http.server 8765
```

请横屏。不要用 `file://`。

## 怎么玩

- 点左侧名单或家谱头像：右侧看出生信息、学历、学校、收入、感情、下一件事
- 升学：县级 / 市级 / 省级（或专科/本科/重点）正常选；花 1 代币走破格名校
- 工作：按学历选司机/技工/公务员/工程师；花代币才走网红
- 恋爱：列表里选人；花代币接触高净值。先恋爱，6 个月后结婚
- 每年 +1 代币

# 家族谱 · 人生模拟（HTML 原型）

现代中国家族树人生模拟小游戏的首版可点击视觉原型。

## 本地打开

```bash
cd family
python3 -m http.server 8765
```

浏览器访问：http://localhost:8765

> 需通过 HTTP 服务打开（ES module 不支持 `file://`）。

## 原型包含

- **家族谱主界面**：2–3 代家庭成员卡片（立绘、年龄、月收入）
- **顶部状态栏**：年月、现金、家庭资产、暂停/继续（3 秒 = 1 个月）
- **人物详情**：智商 / 心情 / 魅力 / 体力
- **选校弹窗**：4 所学校，学费与属性加成不同
- **职业弹窗**：稳定职业 vs 高波动网红
- **恋爱结婚 / 生孩子**：成年未婚点一次选定对象入谱；已婚可生最多 2 个孩子（孙辈）
- **随机事件**：期末奖学金示例（第 6 个月触发）

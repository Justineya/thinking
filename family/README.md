# 家族谱 · 人生模拟（横版原型）

横版家族树。头像很小；**到年龄自动弹窗**，用抽卡决定学校 / 对象 / 工作。

## 本地打开

```bash
cd family
python3 -m http.server 8765
```

手机请横过来。浏览器访问 http://localhost:8765（不要用 `file://`）。

## 怎么玩

- 主界面只有家族谱：小头像 + 年龄 + 月收入
- **满 6 / 12 / 15 / 18 岁**自动弹「抽录取」：N 普通学校，SSR 破格名校（免学费）
- **满 18 岁未婚**自动弹「抽恋爱」：N 普通人，SSR 高净值网红，抽中即结婚入谱
- **满 22 岁学生**自动弹「抽职业」
- 结婚满一年会问要不要生孩子（每对最多 2 个）
- 3 秒 = 1 个月

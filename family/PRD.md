# 陈氏家族 · 产品需求文档（PRD）

**版本：** 0.5  
**日期：** 2026-09-29  
**状态：** 后台体验版；开局改为单人随机穷种子 + 可重开  
**范围内原型：** 竖版 HTML 单页，无广告，原创立绘与玩法（不 1:1 抄抖音素材/公式）

---

## 1. 背景与问题

对标那类「家族树 + 到点弹窗选学校 / 买铺」的小游戏：上头、规则浅、交互少。现有原型已经有家谱、升学、工作、恋爱、灵感、产业页，但体验上有三处明显缺口：

1. **UI 偏木讷**：数字、弹窗、切页都是瞬切，没有「钱在跳、铺在亮、人在动」的反馈。
2. **现金无过程**：月结和买东西时余额一瞬间换成新数，缺少滚动、飞字、正负色。
3. **产业基本不可用**：四块地互不相关，买了不解锁职业、也不解锁下一家店。玩家不知道产业存在的意义。

玩家明确期望：**产业是成长轴**——铺买得越多 → 能当的职位越多 → 又能买更贵的店。学校/工作/恋爱仍是「到点弹列表」，省级/高净值用灵感，不用广告。

---

## 2. 产品目标

| 目标 | 说明 |
|------|------|
| 看得懂 | 第一次打开 10 秒内知道：这是家谱，到年龄会弹窗，钱在头顶跳 |
| 点得少 | 人多了也不靠每人点技能；人生节点自动弹，日常只看树、买铺、花灵感 |
| 产业有用 | 买铺改变「能选什么工作」和「下一格能买什么」 |
| 手感不木 | 现金、灵感、弹窗、解锁都有短动画（200–500ms），不挡操作 |
| 无广告 | 原作绿色「看视频进省级」改为 **花 1 灵感** |

**非目标（本版不做）**

- 实时对战、排行榜、UGC、云存档登录
- 约会小游戏、房产装修模拟
- 复刻对标游戏的素材、任务文案、广告点、精确经济公式

---

## 3. 用户与场景

- **谁：** 想挂机看家族变大的休闲玩家，手机竖屏为主。
- **核心场景：** 一边走时间（约 3 秒 = 1 个月），一边处理弹窗（升学/就业/恋爱/结婚/生子），闲时点产业扩张。
- **成功体验：** 小镇中学 → 市级高中 → 本科 → 进自家餐厅当店长；再买第二家店，解锁厨师/店长岗，下一代更容易就业。

---

## 4. 信息架构

底部三 Tab（已有，保留）：

| Tab | 职责 |
|-----|------|
| 家族 | 家谱主画面；点头像出底部履历 |
| 灵感 | 用灵感兑换现金或全族属性 |
| 产业 | 地块地图：已持有 / 可买 / 锁定 |

顶栏常驻：

- 现金（大数字，**滚动变化**）
- 本月净流入（绿 + / 红 −，月结时弹一次飞字）
- 灵感数量
- 年月 + 暂停

---

## 5. 核心循环

```
时间前进（月）
  → 发工资、扣学费、收铺租  （现金滚动）
  → 有人到年龄 → 弹窗选择
       升学：乡镇 / 县城 / 市级（现金） / 省级（灵感）
       就业：学历 ∩ 已解锁产业岗位
       恋爱 → 满 6 个月 → 结婚入谱 → 满 12 个月可生（每对最多 2 娃）
  → 玩家买铺（满足前置）
       → 解锁对应职业
       → 解锁下一档地块
```

时间在弹窗打开时暂停，关掉后继续。

## 6. 功能需求

### 6.1 家族谱

- 按代纵向：祖辈一对 → 父母一对 → 子女横排。
- 每人：圆头像、姓名、**月流水**（上班绿 +x/月，上学红 −学费/月）。
- 点头像：底部抽屉履历（学历、学校、岗位、感情、四维、下一人生节点提示）。
- 不在履历里堆「选学校/选工作」按钮；那些只走自动弹窗。

### 6.2 升学弹窗（对标图，优化文案密度）

结构：阶段名（初中）→ 大头像 + 年龄角标 + 当前月流水 → 绿字规则一句 → 四个大按钮。

| 按钮 | 支付 | 效果 |
|------|------|------|
| 乡镇 | 入学费现金 | 学费低，智商加成低 |
| 县城 | 入学费现金 | 中档 |
| 市级 | 入学费现金 | 高档，贵 |
| 省级 | **1 灵感** | 免入学费/低学费，智力加成最高 |

钱不够：按钮可点但 toast「现金不够」，不关窗。  
灵感不够：绿色按钮同样 toast，不关窗。

6 / 12 / 15 / 18 岁自动弹对应阶段。学校档次影响后续就业工资档（本版用「智商加成 + 学历标签」近似，不写死对标数值）。

### 6.3 就业（与产业绑定）——本版重点

找工作弹窗：**不是写死四岗**。列表 = 「社会岗」∪ 「已解锁的产业岗」。

**社会岗（默认就有，看学历）：**

| 岗位 | 学历门槛 | 月薪量级 |
|------|----------|----------|
| 网约车 | 高中+ | 低 |
| 工厂技工 | 高中+ | 低 |
| 公务员 | 本科 | 中 |
| 软件工程师 | 本科 | 高 |

**产业岗（买对应铺才出现在列表里）：**

| 产业 | 解锁岗位 | 学历门槛 | 月薪相对社会岗 |
|------|----------|----------|----------------|
| 平房（开局有） | — | — | 不住岗 |
| 便利店 / 餐厅 | 店员、厨师 | 不限 / 高中 | 中低，稳定 |
| 健身房 | 教练 | 高中 | 中，吃魅力 |
| 汽修店 | 技师 | 高中 | 中高 |
| 酒店（后解锁） | 前台、经理 | 高中 / 本科 | 高 |
| 公司（再后） | 职员、主管 | 本科 | 更高 |

同一铺可安排的人数 ≤ 地块 `cap`（编制）。编制满了，该岗仍显示但标注「满员」。

**灵感岗：** 「网红」不进普通列表，单独绿按钮，花 1 灵感；收入高波动。

顺序仍是：**先有工作 → 再恋爱 → 满 6 个月结婚**。

### 6.4 产业（商店）——本版重点

产业页是 **有序地图**，不是四个无关按钮。

**解锁规则（建议表，实现时可配置）：**

| 地块 | 解锁条件 | 购买金 | 月租 |
|------|----------|--------|------|
| 普通平房 | 开局已有 | — | 0（自住） |
| 便利店 | 有平房 | 低 | 低 |
| 餐厅 | 已有便利店 | 中 | 中 |
| 健身房 | 已有便利店 | 中 | 中 |
| 汽修店 | 餐厅或健身任一 | 中高 | 中高 |
| 快捷酒店 | 产业数 ≥ 3 | 高 | 高 |
| 写字楼 | 已有酒店 | 很高 | 很高 |

状态三种：

- **已持有：** 展示月租、在岗人数 `n/cap`，可点看「派谁来上班」（下版可做；本版至少显示编制）。
- **可购买：** 价格 + 预计月租，点一下扣现金，地块翻转动画。
- **未解锁：** 灰态 + 一行条件（「先买便利店」），点了 toast 条件，不扣钱。

买下后：

1. 现金滚动扣除；
2. 地块从灰 → 彩，短暂缩放；
3. toast「解锁岗位：厨师、店员」；
4. 下次就业弹窗出现新岗；已有工作的人**不强制转岗**（避免人多点不过来）。

产业月租计入顶栏「+/月」，发薪日一起滚动进现金。

### 6.5 灵感商店（后台体验版已接）

用灵感买一次性效果，不做转盘。本版商店：

| 项目 | 花费 | 效果 |
|------|------|------|
| 兑换现金 | 1 | +10,000 |
| 大额兑换 | 3 | +50,000 |
| 全族智商/魅力/体力/心情 | 各 2 | 每人 +5 |
| 全员津贴 | 2 | 当月每人临时工资 +1,000 |

另外弹窗绿按钮各花 1 灵感：省级学校、网红岗、高净值对象。

**后台版：** 顶部 GM 条可 +10 / +100 / 设为 999，方便把所有分支点完。

工资、升职、随机事件、记载方式见 [DATA.md](./DATA.md)。**先不用数据库**，规则在 `family/data/*.js`，发生过的事在内存 `eventLog`。

灵感来源：开局若干；每年 +1；后台可无限加。

### 6.6 恋爱 / 结婚 / 生子

保持现有节奏，弹窗视觉与升学同一套卡片。

- 恋爱：列表普通人；绿按钮「接触高净值 · 灵感 1」
- 结婚：谈满 6 个月，婚礼扣现金，对方入谱
- 生子：婚满 12 个月，¥8,000，每对最多 2 个，避免点不过来

## 7. 动效需求（解决「木讷」）

原则：每个状态变化都有 **200–400ms** 反馈，可跳过（点屏幕不排队播长动画）。

| 场景 | 动效 |
|------|------|
| 现金变化 | 数字缓动计数（easeOut）；增加时绿色，减少时红色，持续约 400ms |
| 月结 | 顶栏「本月净流入」旁飞出 `+3,264` 小字上浮消失 |
| 弹窗出现 | 卡片从中心 scale 0.92→1 + 淡入，背景压暗 |
| 点按钮 | 按下缩小 0.98，成功后卡片收起再进下一事件 |
| 买地块 | 地块翻转或亮度扫过；锁图标碎掉 |
| 解锁职业 | 短 toast，不要再套一层模态 |
| 灵感变动 | 票券图标轻晃 + 数字滚动 |
| 切 Tab | 内容横向滑 16px 淡入，不要硬切 |
| 点头像 | 履历抽屉从底滑入 |

**不做：** 长过场、强制看完的角色spine、每秒粒子。

## 8. 经济与节奏（设计约束）

- 开局：**单人**，随机抽穷种子（流水线 / 网约车 / 应届专科 / 辍学待业 / 学徒工），现金大约几百到四五千，无房产。可随时「重开」。
- 乡镇入学费要「随手能点」，市级要「攒一攒」，省级用灵感卡决策。
- 产业月租总和早期应小于全家工资，避免铺子替代「养人」；后期可接近工资，形成扩张欲望。
- 时间：3 秒/月可调；弹窗期间时间停。

精确曲线本版不锁死，实现时用配置表（`enroll` / `tuition` / `cost` / `income` / `unlock`）。

## 9. 界面原则

- 竖屏手机宽度（约 430px），浅蓝背景、白卡片、蓝按钮现金、绿按钮灵感。
- 比对标更干净：无左侧「恢复数据/录制/桌面」条，无宠物喊话。
- 立绘继续用现有原创头像，圆形裁切。
- 文案短：按钮「选择县城初中 -6.17万」，规则一句绿字。

## 10. 版本切分

### P0（下一期必做）

1. 现金/灵感数字滚动 + 月结飞字  
2. 弹窗/切页/买铺短动画  
3. 产业解锁链 + 灰态条件  
4. 就业列表 = 社会岗 + 已解锁产业岗  
5. 买铺 toast 解锁职业  

### P1

- 产业编制 `n/cap` 展示；满员提示  
- 灵感里程碑（买满 3 店 +1 灵感）  
- 履历里显示「可去的店」  

### P2

- 手动把某人派到某店（仍要克制，人多了会崩）  
- 简单本地存档  
- 酒店/写字楼更高档地块

## 11. 成功标准

- 新手不看说明能完成：第一次升学四选一、第一次买解锁的店。  
- 买下餐厅后，下一次就业弹窗里能看到厨师/店员。  
- 未解锁地块点了不会扣钱。  
- 现金从 33.2 万变为 32.1 万时，能看出滚动而不是跳变。  
- 全程无广告、无强制视频按钮。

## 12. 风险

| 风险 | 应对 |
|------|------|
| 产业岗太多，就业弹窗变长 | 每类最多 2 岗；编制满的折成一行灰字 |
| 经济崩（全去当经理） | 经理岗编制 1；学历门槛保留 |
| 动效卡顿 | 只用 CSS transform/opacity + 数字 rAF，可一键减弱 |
| 像换皮 | 文案、经济、无广告、产业↔职业链做出差异 |
